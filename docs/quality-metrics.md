# Метрики качества зон

## Система оценки

Каждая зона оценивается по 100-балльной шкале, разделенной на несколько категорий.

## Категории и веса

### 1. Техническая корректность (20 баллов)

**Критичные ошибки** (автоматически снижают оценку до 0):
- Невалидный формат файлов
- Дубликаты ID
- Недостижимые комнаты
- Битые ссылки на объекты/мобов

**Оценочные метрики**:
- ✓ Синтаксис корректен (5 баллов)
- ✓ Все ID уникальны (5 баллов)
- ✓ Ссылочная целостность (5 баллов)
- ✓ Граф зоны связен (5 баллов)

**Автоматизация**: Полностью автоматизируемо

### 2. Структурная полнота (15 баллов)

**Метрики**:
- Количество комнат (0-3 балла)
  - 5-9 комнат: 1 балл
  - 10-20 комнат: 2 балла
  - 21+ комнат: 3 балла

- Количество уникальных мобов (0-4 балла)
  - 1-2 моба: 1 балл
  - 3-4 моба: 2 балла
  - 5-7 мобов: 3 балла
  - 8+ мобов: 4 балла

- Количество уникальных объектов (0-3 балла)
  - 1-2 объекта: 1 балл
  - 3-5 объектов: 2 балла
  - 6+ объектов: 3 балла

- Наличие квеста (0-2 балла)
  - Нет квеста: 0 баллов
  - Простой квест: 1 балл
  - Сложный квест/цепочка: 2 балла

- Топологическое разнообразие (0-3 балла)
  - Линейная структура: 0 баллов
  - Есть развилки: 2 балла
  - Сложная сеть: 3 балла

**Автоматизация**: Полностью автоматизируемо

### 3. Качество текста (25 баллов)

**Метрики**:

- Орфография и грамматика (0-8 баллов)
  - Автоматическая проверка орфографии
  - 0 ошибок: 8 баллов
  - 1-3 ошибки: 6 баллов
  - 4-7 ошибок: 4 балла
  - 8-15 ошибок: 2 балла
  - 16+ ошибок: 0 баллов

- Длина описаний (0-5 баллов)
  - Все описания комнат 100-500 символов: 5 баллов
  - 80%+ в диапазоне: 3 балла
  - 60%+ в диапазоне: 1 балл

- Сенсорное разнообразие (0-7 баллов)
  - Подсчет упоминаний:
    - Визуальные детали (цвет, свет, формы)
    - Звуки
    - Запахи
    - Тактильные ощущения (температура, текстура)
    - Вкус (где уместно)
  - Оценка: количество типов чувств * 1.5 балла (макс 7)

- Единство стиля (0-5 баллов)
  - Проверка на анахронизмы и современные слова
  - Отсутствие нарушений: 5 баллов
  - 1-2 нарушения: 3 балла
  - 3-5 нарушений: 1 балл
  - 6+ нарушений: 0 баллов

**Автоматизация**: ~70% автоматизируемо (орфография, длина, подсчет сенсорных слов)

### 4. Атмосферность и оригинальность (25 баллов)

**Метрики** (в основном ручная оценка):

- Уникальность концепции (0-10 баллов)
  - 10: Полностью оригинальная, незабываемая концепция
  - 7-9: Свежий взгляд на известную тему
  - 4-6: Стандартная тема с интересными деталями
  - 1-3: Клише с минимальными отличиями
  - 0: Полная копия типичной fantasy-локации

- Атмосферность (0-10 баллов)
  - 10: Описания создают яркий, погружающий образ
  - 7-9: Хорошая атмосфера, но есть пробелы
  - 4-6: Базовая атмосфера без особых деталей
  - 1-3: Сухие, формальные описания
  - 0: Отсутствие атмосферности

- Связь с фольклором (0-5 баллов)
  - 5: Органично вплетен славянский фольклор
  - 3-4: Есть фольклорные элементы
  - 1-2: Слабая связь
  - 0: Нет связи со славянской темой

**Автоматизация**: ~20% (проверка на клише-слова, наличие описания фольклорной основы)

### 5. Игровой баланс (15 баллов)

**Метрики**:

- Соответствие уровней (0-5 баллов)
  - Уровни мобов в пределах ±2 от заявленного: 5 баллов
  - Уровни мобов в пределах ±4: 3 балла
  - Больший разброс: 1 балл

- Баланс наград (0-5 баллов)
  - Опыт и золото соответствуют формулам: 5 баллов
  - Небольшие отклонения (±20%): 3 балла
  - Значительные отклонения: 1 балл

- Баланс сложности (0-5 баллов)
  - Урон мобов соответствует уровню: 5 баллов
  - Небольшие проблемы: 3 балла
  - Несбалансированность: 1 балл

**Автоматизация**: ~80% (формулы баланса)

## Итоговая оценка

**Градация качества**:
- 90-100 баллов: Отлично - готово к интеграции
- 75-89 баллов: Хорошо - нужны минорные правки
- 60-74 балла: Удовлетворительно - требуется доработка
- 45-59 баллов: Плохо - существенная переработка
- 0-44 балла: Очень плохо - рекомендуется начать заново

## Автоматизируемость

### Полностью автоматизируемо (~50% от общей оценки):
- Техническая корректность (20 баллов)
- Структурная полнота (15 баллов)
- Игровой баланс (12 баллов из 15)

### Частично автоматизируемо (~20% от общей оценки):
- Качество текста (17 баллов из 25)
- Атмосферность (5 баллов из 25)

### Ручная оценка (~30% от общей оценки):
- Качество текста (8 баллов из 25)
- Атмосферность (20 баллов из 25)
- Игровой баланс (3 балла из 15 - экспертная оценка fun factor)

## Формулы баланса

### Опыт за моба
```
exp = base_exp * level^2 * difficulty_modifier
где:
  base_exp = 10
  difficulty_modifier: 0.8-1.5 в зависимости от сложности моба
```

### Золото за моба
```
gold = base_gold * level * difficulty_modifier
где:
  base_gold = 5
```

### Урон моба
```
avg_damage = player_hp(level) * 0.1 для обычного моба
avg_damage = player_hp(level) * 0.15 для сильного моба
avg_damage = player_hp(level) * 0.25 для босса
где:
  player_hp(level) = 100 + level * 20 (примерная формула)
```

### Стоимость предметов
```
item_cost = base_cost * (stat_bonus^1.5) * rarity_modifier
где:
  rarity_modifier: common=1.0, uncommon=2.0, rare=4.0, epic=8.0
```

## Словари для автоматической проверки

### Запрещенные клише
- эльф, эльфийский
- хоббит
- орк (стандартный fantasy-орк, но можно использовать в контексте славянской мифологии)
- дварф, гном (в fantasy-смысле)
- мифрил, адамантит
- меч-кладенец (слишком заезженно, если нет оригинальной трактовки)

### Анахронизмы и современные слова
- компьютер, телефон, интернет (очевидно)
- окей, супер, класс
- босс (в значении начальник, но можно как игровой термин)
- круто, прикольно
- реально, конкретно

### Сенсорные слова (для подсчета)

**Визуальные**: цвет, свет, тьма, блеск, сияние, тень, мрак, яркий, тусклый, переливается, искрится, мерцает, ...

**Звуковые**: звук, шум, тишина, эхо, шепот, крик, скрип, звон, шорох, гул, жужжание, ...

**Обонятельные**: запах, аромат, вонь, благоухание, пахнет, смердит, ...

**Тактильные**: холодный, теплый, жаркий, влажный, сухой, гладкий, шершавый, липкий, ...

**Вкусовые**: сладкий, горький, кислый, соленый, вкус, привкус, ...

## Пример отчета валидации

```
ОЦЕНКА ЗОНЫ: "Соляные копи"
================================

ТЕХНИЧЕСКАЯ КОРРЕКТНОСТЬ: 20/20
  ✓ Синтаксис корректен
  ✓ Все ID уникальны
  ✓ Ссылочная целостность
  ✓ Граф связен

СТРУКТУРНАЯ ПОЛНОТА: 13/15
  + 12 комнат (2 балла)
  + 4 уникальных моба (2 балла)
  + 6 объектов (3 балла)
  + Простой квест (1 балл)
  + Топология: есть развилки (2 балла)
  - Рекомендация: добавить еще 1-2 моба для разнообразия

КАЧЕСТВО ТЕКСТА: 21/25
  + Орфография: 1 ошибка найдена (6 баллов)
  + Длина описаний: 90% в норме (4 балла)
  + Сенсорность: 4 типа чувств (6 баллов)
  + Стиль: 2 анахронизма (3 балла)
  - Найдены ошибки: "сталоктит" -> "сталактит"
  - Анахронизмы: "круто переливается", "конкретная опасность"

АТМОСФЕРНОСТЬ: [требуется ручная оценка]
  ? Уникальность концепции
  ? Атмосферность описаний
  + Связь с фольклором: упоминание духов-лизунов (3 балла)

ИГРОВОЙ БАЛАНС: 13/15
  + Уровни мобов: 12-14 (заявлено 13) (5 баллов)
  + Награды: в пределах формул (5 баллов)
  + Сложность: урон соответствует (5 баллов)
  - Урон босса "Соляной Голем" немного завышен (рекомендация)

АВТОМАТИЧЕСКАЯ ОЦЕНКА: 67/75 возможных
РУЧНАЯ ОЦЕНКА: требуется
СТАТУС: Хорошее качество, требуется ручное ревью и минорные правки
```
