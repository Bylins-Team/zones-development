## Что было улучшено

### 1. Мобы - роли и расы (КРИТИЧНО)

**Добавлено для каждого моба:**
- `role` - роль в бою (TRASH, BOSS, TANK)
- `race` - раса из движка (CONSTRUCT, ZOMBIE, SPIRIT, BASIC)
- Все флаги поведения из движка (15+ флагов вместо 4)
- Тип атаки (`attack_type`)

**Примеры:**
```yaml
# salt_golem
role: "TRASH"
race: "CONSTRUCT"
no_charm: true      # Конструкт нельзя очаровать
no_sleep: true      # Конструкт не спит
no_blind: true      # Нет глаз
aware: true         # Нельзя backstab

# salt_guardian (БОСС)
role: "BOSS"
race: "CONSTRUCT"
sentinel: true      # Не покидает позицию
aggro_range: 1      # Атакует при приближении

# salt_ooze (ТАНК)
role: "TANK"
race: "BASIC"
no_bash: true       # Бесформенный
damage: "2d4+2"     # Меньше урона (танк)
```

### 2. Баланс наград (КРИТИЧНО)

**Пересчитано по формулам из движка:**

| Моб           | Уровень | Роль  | Было exp | Стало exp | Было gold  | Стало gold |
|---------------|---------|-------|----------|-----------|------------|------------|
| salt_golem    | 13      | TRASH | 800      | **1690**  | 50-150     | **45-85**  |
| salt_mummy    | 11      | TRASH | 500      | **1210**  | 20-60      | **38-72**  |
| salt_spirit   | 12      | TRASH | 600      | **1440**  | 10-30      | **42-78**  |
| salt_guardian | 15      | BOSS  | 2000     | **6750**  | 200-500    | **262-487**|
| salt_ooze     | 10      | TANK  | 400      | **1000**  | 5-20       | **35-65**  |

**Формулы:**
- Опыт: `level^2 * role_mult` (10 для TRASH, 30 для BOSS)
- Золото: `level * role_mult * (0.7-1.3)` (5 для TRASH, 25 для BOSS)
