# Профили конфигурации GPU

Zone Generator поддерживает профили для разных GPU. Профиль определяет какие модели использовать на каждом этапе генерации.

## Как использовать

```bash
# Список всех профилей
python -m tools.generator.main --list-profiles

# Использовать конкретный профиль
python -m tools.generator.main --profile rtx4070ti-max --theme "Пещера" --level 10-15
```

## Доступные профили

### RTX 4070 Ti (12GB VRAM)

**default** (по умолчанию)
- Описание: Сбалансированный режим - 14b для креативных этапов, 7b для структурных
- VRAM: 12GB
- Модели: qwen2.5:14b + qwen2.5:7b
- Использование: Оптимальное соотношение качества и скорости

**rtx4070ti-max**
- Описание: Максимальное качество - все этапы на 14b
- VRAM: 12GB
- Модели: только qwen2.5:14b
- Использование: Лучшее качество генерации, чуть медленнее

**rtx4070ti-light**
- Описание: Быстрый режим - все этапы на 7b
- VRAM: 12GB
- Модели: только qwen2.5:7b
- Использование: Быстрая генерация, немного ниже качество

### RTX 2080 Ti (11GB VRAM)

**rtx2080ti-balanced**
- Описание: Сбалансированный - 14b креативные, 7b структурные
- VRAM: 11GB
- Модели: qwen2.5:14b + qwen2.5:7b
- Использование: Оптимально для RTX 2080 Ti

**rtx2080ti-max**
- Описание: Максимум - все на 14b (может быть медленно)
- VRAM: 11GB
- Модели: только qwen2.5:14b
- Использование: Лучшее качество, GPU может перегружаться

**rtx2080ti-light**
- Описание: Легкий режим - все на 7b
- VRAM: 11GB
- Модели: только qwen2.5:7b
- Использование: Быстрая генерация

### Универсальные профили

**low-vram**
- Описание: Для слабых GPU (< 8GB VRAM)
- VRAM: 6-8GB
- Модели: только qwen2.5:7b
- Использование: GTX 1060 6GB, RTX 3060, и подобные

**cpu-only**
- Описание: Режим CPU (без GPU)
- VRAM: N/A
- Модели: только qwen2.5:7b
- Использование: Очень медленно, только для тестирования

## Создание своего профиля

Отредактируйте `tools/generator/profiles.py`:

```python
MODEL_PROFILES = {
    # ...
    'my-custom-profile': {
        'description': 'Мой кастомный профиль',
        'vram': '16GB',
        'models': {
            'idea': 'qwen3:8b',
            'lore': 'qwen3:8b',
            'rooms': 'qwen2.5:14b',
            'mobs': 'qwen2.5:14b',
            'quests': 'qwen2.5:14b',
            'structure': 'qwen2.5:7b',
            'objects': 'qwen2.5:7b',
            'refiner': 'qwen3:8b',
        }
    }
}
```

## Какой профиль выбрать?

### RTX 4070 Ti (12GB)
- 🎯 **Рекомендуется:** `default` или `rtx4070ti-max`
- Быстро: `rtx4070ti-light`

### RTX 2080 Ti (11GB)
- 🎯 **Рекомендуется:** `rtx2080ti-balanced`
- Качество: `rtx2080ti-max` (если не перегревается)
- Быстро: `rtx2080ti-light`

### RTX 3060 / 3070 (8GB)
- 🎯 **Рекомендуется:** `low-vram`

### GTX 1060 / 1070 (6GB)
- 🎯 **Рекомендуется:** `low-vram`

### Без GPU
- `cpu-only` (ОЧЕНЬ медленно, не рекомендуется)

## Этапы генерации

Профили определяют модель для каждого этапа:

1. **idea** - Генерация концепции зоны (креативный)
2. **lore** - Фольклор и нарратив (креативный)
3. **structure** - Топология графа комнат (структурный)
4. **rooms** - Описания комнат (креативный)
5. **mobs** - Мобы и характеристики (креативный)
6. **objects** - Объекты (структурный)
7. **quests** - Квесты (креативный)
8. **refiner** - Финальная полировка (креативный)

**Креативные этапы** - лучше использовать более мощные модели (14b)
**Структурные этапы** - можно использовать легкие модели (7b)
