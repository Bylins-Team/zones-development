# Разработка зон для МУД "Былины"

Репозиторий для создания и тестирования новых игровых зон для русской текстовой игры "Былины".

> **Прежде чем строить — прочитай официальную документацию билдера:**
> [портал билдера](https://www.bylins.su/builder/) ·
> [OLC-редакторы](https://www.bylins.su/builder/olc/) ·
> [советы билдеру](https://www.bylins.su/advice/2builder).
> Практические грабли, которых в OLC-доках нет (двери `keyword|vkeyword`, `narg`
> триггеров, `NODECAY`, поля описаний, DG-приёмы, тест-режим) — в [`AGENTS.md`](AGENTS.md).

## О проекте

Былины - это бесплатная русскоязычная сетевая текстовая игра (MUD), основанная на русских сказках и преданиях. В отличие от типичных MUD с эльфами и хоббитами, мир Былин погружает игроков в атмосферу славянского фольклора.

## Процесс разработки зоны

### Вариант 1: Автоматическая генерация (рекомендуется) 🆕

**Zone Generator** - автоматизация создания зон с использованием LLM:

```bash
# Генерация новой зоны (10-30 минут вместо 3-5 часов!)
python3 -m tools.generator.main \
  --theme "заброшенная мельница" \
  --level "10-15"
```

**Преимущества:**
- ✨ Генерация полной зоны за 10-30 минут
- ✨ Автоматический баланс мобов (exp, gold, damage)
- ✨ Интерактивный контроль каждого этапа
- ✨ Соответствие славянскому фольклору

Подробнее: [tools/generator/USAGE.md](tools/generator/USAGE.md)

### Вариант 2: Ручная разработка

1. **Концепт** - создание идеи в `zones/ideas/`
2. **Черновик** - детальная разработка в `zones/draft/`
3. **Валидация** - проверка качества с помощью автоматических инструментов
   ```bash
   # Валидация с LLM-оценкой (рекомендуется)
   python3 tools/validator.py zones/draft/your-zone.yaml

   # Быстрая валидация без LLM
   python3 tools/validator.py --no-llm zones/draft/your-zone.yaml
   ```
4. **Ревью** - ручная проверка
5. **Утверждение** - перенос в `zones/approved/`

## Система оценки качества

Валидатор оценивает зоны по 100-балльной шкале:

- **20 баллов** - Техническая корректность (уникальность ID, ссылочная целостность, связность)
- **15 баллов** - Структурная полнота (количество комнат, мобов, объектов, топология)
- **25 баллов** - Качество текста (длина описаний, сенсорные детали, стиль, орфография)
- **15 баллов** - Игровой баланс (уровни мобов, награды, урон)
- **5 баллов** - Атмосферность (фольклорная основа, атмосферные сообщения)
- **20 баллов** - Экспертная LLM-оценка (атмосфера, уникальность, соответствие фольклору)

**Пороги качества:**
- **90+ баллов** ✓✓✓ - Отлично, готово к интеграции
- **75-89 баллов** ✓✓ - Хорошо, нужны минорные правки
- **60-74 балла** ✓ - Удовлетворительно, требуется доработка
- **< 60 баллов** ✗ - Требуется существенная переработка

## Основные принципы

- Опора на славянский фольклор и русские сказки
- Уникальность и оригинальность (избегать клише)
- Атмосферность и погружение
- Игровой баланс
- Качественное описание

## LLM-оценка качества

Валидатор поддерживает экспертную оценку зон с использованием больших языковых моделей (Qwen2.5:14b) через Ollama.

**Быстрый старт:**

```bash
# 1. Запустить Ollama в Docker с GPU (рекомендуется)
docker run -d --gpus all --restart=unless-stopped --name ollama \
  -p 11434:11434 -v ollama:/root/.ollama ollama/ollama

# 2. Скачать модель для русского языка (~9GB)
docker exec ollama ollama pull qwen2.5:14b

# 3. Запустить валидацию
python3 tools/validator.py zones/draft/salt-mines-example.yaml
```

**Примечание:** Для GPU требуется nvidia-container-toolkit. Инструкции: `docs/llm-evaluation.md`

LLM оценивает атмосферность, уникальность и соответствие славянскому фольклору. Подробнее: `docs/llm-evaluation.md`.
